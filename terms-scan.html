2. ФУНКЦИОНАЛ ПРИЛОЖЕНИЯ

2.1. Описание функций
Приложение CashIQ Scan предоставляет следующие функции:

  • выбор из галереи устройства одного или нескольких скриншотов с условиями кэшбэка по банковским картам;
  • ввод названия карты и выбор банка из встроенного справочника (в том числе с автоопределением по имени файла);
  • распознавание текста (OCR) локально на устройстве Пользователя;
  • определение категорий кэшбэка и процентов, формирование структурированных данных о картах;
  • редактирование распознанных данных;
  • экспорт подготовленных данных в файл формата JSON и передача его через стандартные системные механизмы («Поделиться»);
  • ведение встроенного справочника банков и логотипов, который обновляется исключительно через обновления Приложения.

2.2. Ограничения функционала
Приложение НЕ предоставляет:

  • банковских, инвестиционных или платежных услуг;
  • юридически значимых финансовых рекомендаций;
  • гарантий точности распознавания и актуальности информации о банковских программах.

2.3. Технические требования
Для работы Приложения требуется:

  • Android 11.0+ (или иная версия, указанная в магазине приложений);
  • доступ к галерее/хранилищу устройства (для выбора скриншотов);
  • доступ к интернету не обязателен для основной функции распознавания, но может потребоваться для загрузки обновлений Приложения (если они распространяются через магазин).

2.4. Процесс установки
Для установки Приложения:

  • скачайте APK-файл с официального сайта cashiq.ru или из RuStore (или иного официального магазина);

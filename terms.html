Условия использования приложения

Правила и условия использования приложения CashUp!

УСЛОВИЯ ИСПОЛЬЗОВАНИЯ ПРИЛОЖЕНИЯ CASHUP!

Действительно с 20 ноября 2025 года

1. ОБЩИЕ ПОЛОЖЕНИЯ

1.1. Статус Разработчика

Приложение CashUp! (далее — "Приложение") разработано и поддерживается физическим лицом (далее — "Разработчик"), не зарегистрированным в качестве индивидуального предпринимателя. Приложение распространяется на некоммерческой основе.

1.2. Согласие с Условиями

Начиная использование Приложения, вы подтверждаете свое согласие с настоящими Условиями использования. Если вы не согласны с какими-либо положениями, вы должны немедленно прекратить использование Приложения.

1.3. Возрастные ограничения

Приложение предназначено для пользователей, достигших 16-летнего возраста. Используя Приложение, вы подтверждаете, что соответствуете данному возрастному требованию.

2. ФУНКЦИОНАЛ ПРИЛОЖЕНИЯ

2.1. Описание услуг

CashUp! предоставляет следующие услуги:

  • Анализ условий кэшбэка банковских карт на основе предоставленной информации пользователем
  • Рекомендации по выбору оптимальной карты для покупок
  • Учет и анализ расходов
  • Геолокационные уведомления о выгодных предложениях

2.2. Ограничения функционала

Приложение НЕ предоставляет:

  • Брокерских или банковских услуг
  • Инвестиционных рекомендаций

2.3. Технические требования

Для работы Приложения требуется:

  • Android 8.0+
  • Доступ к интернету (для отдельных функций)
  • Разрешение на использование геолокации (опционально)

2.4. Процесс установки

Для установки Приложения:

  • Скачайте APK-файл с официального сайта mycashup.ru
  • Разрешите установку из неизвестных источников (только для Android)
  • Следуйте инструкциям установки

3. СТАТУС РАЗРАБОТЧИКА И ОГРАНИЧЕНИЯ ОТВЕТСТВЕННОСТИ

3.1. Некоммерческий статус

Разработчик:

  • Не является индивидуальным предпринимателем
  • Не получает доход от распространения Приложения
  • Не несет налоговых обязательств, связанных с Приложением

3.2. Ограничение ответственности

РАЗРАБОТЧИК НЕ НЕСЕТ ОТВЕТСТВЕННОСТИ ЗА:

  • Финансовые потери или убытки пользователей
  • Неточности в информации о кэшбэке
  • Изменения условий банковских программ
  • Технические сбои и недоступность Приложения
  • Действия третьих лиц

3.3. Отказ от гарантий

Приложение предоставляется "как есть". Разработчик не дает никаких гарантий относительно:

  • Соответствия ожиданиям пользователя
  • Точности предоставляемых данных

4. ОБРАБОТКА ПЕРСОНАЛЬНЫХ ДАННЫХ

4.1. Принципы обработки данных

Разработчик обязуется:

  • Обрабатывать данные в соответствии с Федеральным законом № 152-ФЗ
  • Не передавать данные третьим лицам, кроме случаев, указанных в п. 4.4
  • Обеспечивать конфиденциальность данных
  • Собирать только минимально необходимые данные для функционирования Приложения

4.2. Типы собираемых данных

Приложение может обрабатывать:

  • Информацию о банковских картах (условия кашбэка, категории)
  • Данные о местоположении (только с явного согласия)
  • Статистику использования Приложения
  • Технические данные устройства

4.3. Хранение данных

Все данные пользователей:

  • Хранятся локально на устройстве
  • Могут быть удалены пользователем в любой момент
  • Не передаются на серверы Разработчика

4.4. Использование Яндекс AppMetrica

Для анализа использования Приложения и улучшения его функциональности используется сервис Яндекс AppMetrica, который может собирать следующие данные:

  • Техническая информация об устройстве (модель, версия ОС)
  • Статистика использования функций Приложения
  • Данные о сбоях и ошибках
  • Информация о сессиях и событиях в Приложении

4.5. Особенности работы с Яндекс AppMetrica

Сбор данных через Яндекс AppMetrica осуществляется с соблюдением следующих принципов:

  • Собранные данные анонимизированы и не позволяют идентифицировать личность пользователя
  • Данные передаются и хранятся на серверах ООО "Яндекс" (Россия)
  • Яндекс обрабатывает данные в соответствии со своей Политикой конфиденциальности

5.1. Авторские права

Разработчик заявляет о своих авторских правах на следующие объекты:

  • Название "CashUp!"
  • Исходный код Приложения
  • Дизайн и пользовательский интерфейс
  • Логотипы и визуальные элементы
  • Документацию и методические материалы

5.2. Правовой статус объектов

Указанные в п. 5.1 объекты:

  • Являются результатом интеллектуальной деятельности Разработчика
  • Охраняются в соответствии с частью 4 Гражданского кодекса РФ
  • Не прошли государственную регистрацию, но защищаются авторским правом
  • Признаются охраняемыми с момента их создания

5.3. Ограничения использования

Пользователю запрещается:

  • Копировать, модифицировать или декомпилировать Приложение
  • Использовать объекты интеллектуальной собственности в коммерческих целях
  • Создавать производные продукты на основе Приложения
  • Использовать название "CashUp!" для собственных проектов

5.4. Авторское право

В соответствии со ст. 1257 ГК РФ, авторские права возникают с момента создания произведения и не требуют обязательной регистрации. Разработчик сохраняет все личные неимущественные и исключительные права на Приложение.

6. УСЛОВИЯ РАСПРОСТРАНЕНИЯ

6.1. Бесплатное распространение

Приложение распространяется:

  • На безвозмездной основе
  • Через официальный сайт

6.2. Отсутствие коммерческой деятельности

Разработчик:

  • Не взимает плату за использование Приложения
  • Не размещает рекламу в Приложении
  • Не получает комиссионные от банков или партнеров

7. ЗАКЛЮЧИТЕЛЬНЫЕ ПОЛОЖЕНИЯ

7.1. Изменение Условий

Разработчик оставляет право:

  • Вносить изменения в настоящие Условия
  • Уведомлять пользователей об изменениях через Приложение
  • Требовать принятия новых Условий для продолжения использования

7.2. Прекращение использования

Пользователь вправе:

  • Прекратить использование Приложения в любой момент
  • Удалить Приложение со своего устройства
  • Требовать удаления своих данных (при их наличии)

7.3. Разрешение споров

Все споры подлежат разрешению:

  • Путем переговоров между пользователем и Разработчиком
  • В соответствии с законодательством Российской Федерации
  • По месту жительства Разработчика

CashUp — максимум кэшбэка с каждой покупки
CashUp помогает обычным людям получать больше денег обратно с повседневных покупок за счет умного подбора банковских карт под каждую категорию трат. Лендинг по адресу mycashup.ru объясняет, как работает сервис, и ведет пользователя к установке приложения.​

Демо
Сайт: https://mycashup.ru

Репозиторий лендинга: https://github.com/li-n-drew/landing

О продукте CashUp
CashUp — это личный финансовый помощник, который показывает, какую карту выгоднее использовать в конкретной ситуации: супермаркет, АЗС, рестораны и другие категории. Пользователь добавляет свои карты и условия кэшбэка, а приложение подсказывает оптимальный вариант, чтобы не терять деньги на каждодневных тратах.​

Задача лендинга
Лендинг mycashup.ru создан для того, чтобы быстро и понятно донести ценность CashUp до широкой аудитории. Страница показывает ключевые выгоды, реальные сценарии использования и простую «дорожку» из трёх шагов: добавить карты, получать подсказки, забирать максимальный кэшбэк.​

Маркетинговые акценты
Экономия без усилий: сервис сам подсказывает лучшую карту для каждой покупки.

Уверенность и безопасность: данные карт хранятся только на устройстве пользователя.

Доверие к продукту: разработчик лично тестирует каждую функцию и отвечает на вопросы пользователей.

Экспертность: за CashUp стоит более 10 лет опыта в финансовой сфере, что повышает качество рекомендаций.​

Ключевые блоки лендинга
Блок ценности: как CashUp помогает получать максимум выгоды с каждой покупки.

Блок преимуществ: личный контроль, безопасность данных, живая поддержка разработчика.

Блок функционала: подбор лучшей карты, учет всех карт пользователя, аналитика кэшбэка по месяцам и категориям, советы по использованию.

Блок «3 простых шага»: понятное объяснение пути пользователя от установки до первых выгод.​

Техническая информация
Основной файл: index.html — статический лендинг, оптимизированный под мобильные устройства.

Хостинг: GitHub Pages с подключенным доменом mycashup.ru.

Репозиторий: https://github.com/li-n-drew/landing — код верстки и статики лендинга.​

Автор
CashUp и лендинг mycashup.ru создаются независимым разработчиком, который сам активно пользуется банковскими продуктами и кэшбэк‑программами. Цель проекта — дать простым пользователям удобный инструмент, чтобы каждый месяц получать ощутимый дополнительный доход за счет правильного выбора карт.​

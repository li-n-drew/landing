Политика конфиденциальности

Приложение CashIQ Scan Действует с момента установки

1. ОБЩИЕ ПОЛОЖЕНИЯ

1.1. Настоящая Политика конфиденциальности (далее — «Политика») регулирует порядок обработки и защиты персональных данных пользователей (далее — «Пользователь», «Вы») мобильного приложения CashIQ Scan (далее — «Приложение»).

1.2. Приложение разработано и поддерживается физическим лицом Ли Андреем Максимовичем (далее — «Разработчик»).

1.3. Используя Приложение, Пользователь подтверждает своё согласие с условиями настоящей Политики. В случае несогласия Пользователь обязан прекратить использование Приложения.

1.4. Настоящая Политика разработана в соответствии с Федеральным законом от 27.07.2006 № 152-ФЗ «О персональных данных» и иными нормативными правовыми актами Российской Федерации.

2. КАКИЕ ДАННЫЕ ОБРАБАТЫВАЮТСЯ

2.1. Приложение не собирает, не передаёт и не хранит персональные данные Пользователя на серверах Разработчика. Вся обработка данных происходит исключительно на устройстве Пользователя.

2.2. Приложение может обрабатывать следующие виды данных, которые вводятся или загружаются Пользователем:

  • Информация о банковских картах: название карты, банк-эмитент, категории кэшбэка, проценты и лимиты — все данные вводятся Пользователем вручную или распознаются со скриншотов.
  • Изображения (скриншоты), выбранные из галереи устройства для распознавания текста (OCR).
  • Технические параметры устройства (модель, версия ОС, язык системы) — используются только для обеспечения корректной работы Приложения и не покидают устройство.

2.3. Все указанные данные хранятся исключительно в локальном хранилище устройства Пользователя и никогда не передаются Разработчику или третьим лицам.

3. ОБРАБОТКА ДАННЫХ И ЕЁ ЦЕЛИ

3.1. Обработка данных осуществляется исключительно для выполнения следующих функций Приложения:

  • распознавание текста на скриншотах с использованием локального OCR;
  • структурирование и отображение информации о кэшбэке;
  • экспорт данных в формат JSON для дальнейшего использования Пользователем.

3.2. Никакие персональные данные не используются для таргетинга рекламы, маркетинговых исследований или иных целей, не связанных с непосредственным функционированием Приложения.

4. ПЕРЕДАЧА ДАННЫХ ТРЕТЬИМ ЛИЦАМ

4.1. Разработчик не передаёт какие-либо данные, обрабатываемые Приложением, третьим лицам, за исключением случаев, прямо предусмотренных законодательством Российской Федерации.

4.2. Приложение не использует сторонние аналитические сервисы (включая, но не ограничиваясь, Яндекс Метрику, Google Analytics, Firebase и т.п.). Сбор статистики использования не осуществляется.

4.3. Единственный случай, когда данные могут быть переданы, — это действие самого Пользователя при использовании функции «Поделиться» для экспорта JSON-файла. В этом случае передача осуществляется по выбору Пользователя через стандартные механизмы операционной системы (например, отправка по электронной почте, мессенджеру и т.п.) и полностью контролируется Пользователем.

5. ХРАНЕНИЕ И УДАЛЕНИЕ ДАННЫХ

5.1. Все данные, созданные в процессе работы Приложения, сохраняются в зашифрованном виде во внутреннем хранилище устройства Пользователя.

5.2. Пользователь может в любой момент удалить все данные, связанные с Приложением, двумя способами:

  • через настройки Приложения (если предусмотрена функция сброса данных);
  • путём полного удаления Приложения с устройства (при этом все локальные данные уничтожаются).

5.3. Разработчик не имеет доступа к данным Пользователя и не может их восстановить после удаления Приложения.

6. ЗАЩИТА ДАННЫХ

6.1. Разработчик принимает все необходимые организационные и технические меры для защиты данных Пользователя от несанкционированного доступа, уничтожения, изменения или распространения.

6.2. Поскольку все данные хранятся локально на устройстве Пользователя, основная ответственность за их сохранность лежит на Пользователе (использование блокировки экрана, антивирусного ПО и т.п.).

7. ПРАВА ПОЛЬЗОВАТЕЛЯ

7.1. Пользователь имеет право:

  • получать информацию о том, какие данные обрабатываются Приложением (вся информация изложена в настоящей Политике);
  • удалить свои данные в любое время (способ описан в п. 5.2);
  • обратиться к Разработчику с запросом об уточнении или разъяснении обработки данных (контакты указаны в разделе 9).

7.2. В связи с тем, что данные хранятся только локально, у Разработчика физически отсутствует возможность предоставить копию данных или удалить их удалённо — все операции выполняются Пользователем самостоятельно на своём устройстве.

8. ИЗМЕНЕНИЕ ПОЛИТИКИ

8.1. Разработчик оставляет за собой право вносить изменения в настоящую Политику конфиденциальности. Новая редакция вступает в силу с момента её размещения на сайте cashiq.ru.

8.2. Продолжение использования Приложения после изменения Политики означает согласие Пользователя с обновлённой редакцией.
